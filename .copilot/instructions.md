# GitHub Copilot Configuration for Java Examples Project

## Project Context
This repository contains educational Java examples demonstrating various programming concepts from basic syntax to advanced topics like design patterns and concurrency.

## Coding Standards
- Follow Google Java Style Guide
- Use meaningful variable and method names
- Include comprehensive JavaDoc comments
- Prefer composition over inheritance where appropriate
- Use modern Java features (Java 8+)

## Code Organization
- Package structure: src.{category}.{concept}
- Each example should be self-contained and runnable
- Include main() method for demonstration
- Provide clear console output explaining what's happening

## Documentation Guidelines
- Every public class should have a class-level JavaDoc comment
- Public methods should have method-level JavaDoc with @param and @return tags
- Include @author and @version tags
- Add inline comments for complex logic

## Example Categories
- basics: Fundamental Java concepts (variables, loops, conditionals)
- oop: Object-oriented programming (inheritance, polymorphism, encapsulation)
- datastructures: Custom implementations of common data structures
- algorithms: Common algorithms and their implementations
- patterns: Design pattern implementations
- advanced: Advanced topics (concurrency, streams, reflection)

## Best Practices
- Handle exceptions appropriately
- Close resources properly (try-with-resources)
- Use appropriate access modifiers
- Prefer immutable objects where possible
- Write testable code

## Learning Focus
Each example should:
1. Demonstrate a specific concept clearly
2. Include explanatory comments
3. Show practical usage
4. Handle edge cases
5. Follow Java best practices
